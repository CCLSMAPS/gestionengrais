# تسيير مخزون الأسمدة - CCLS ADRAR (`gestionengrais`)

نظام ويب متكامل لتسيير مخزون الأسمدة، استقبال ملفات الفلاحين، الفواتير والتسليمات، أذون الخروج، إحصائيات الزراعات، لوحة القيادة التحليلية، وإدارة المستخدمين والصلاحيات لتعاونية الحبوب والبقول الجافة أدرار (**CCLS ADRAR**).

## الوحدات والصفحات الرئيسية

| الصفحة | الوصف |
|---|---|
| `analytics.html` | لوحة التحكم التحليلية (Recharts): استهلاك الأسمدة حسب المحصول، توزيع الواردات والتسليمات الشهرية، المؤشرات المالية (دج)، وتنبيهات إعادة الطلب |
| `reception.html` | استقبال ملفات الفلاحين (*Accusé de réception*)، كشف التكرار التلقائي، وطباعة/تصدير الوصل |
| `index.html` | تسجيل الواردات (مع تتبع تواريخ الصلاحية)، الفواتير متعددة البنود، وعمليات الاستلام |
| `bons.html` | إصدار وطباعة أذون الخروج (*Bon de sortie*) وجدول المتابعة (*Etat de sortie*) |
| `warehouse.html` | تسيير المخازن، تنبيهات النفاد ونقطة إعادة الطلب، الرسم البياني للمخزون، وسجل التعديلات |
| `crops.html` | إحصائيات الزراعات والمساحات المزروعة وتصدير PDF / CSV |
| `users.html` | إدارة المستخدمين، المناصب، والصلاحيات |

## التقنيات المستخدمة

- **الخادم**: Node.js + Express (`server.js`) مع قائمة بيضاء صارمة للملفات المسموحة، ضغط `gzip`، ورؤوس أمان HTTP (`CSP`, `nosniff`, `Referrer-Policy`).
- **الواجهة**: HTML5 RTL عربية (`IBM Plex Sans Arabic` + `IBM Plex Mono`)، نظام ألوان فاتح/داكن تلقائي، وCSS متجاوب (`common.css` + `common.js`).
- **الرسوم والتقارير**: React 19 + TypeScript + Recharts + jsPDF + html2canvas تُجمع عبر `esbuild` (`build.mjs` إلى `dist/*.js`).
- **قاعدة البيانات والمصادقة**: Supabase (PostgreSQL + Auth + Row Level Security).

## التشغيل والتطوير محلياً

```bash
npm install
npm run build
npm run lint
npm test
npm start
```

يعمل الخادم افتراضياً على المنفذ `3000` (`http://0.0.0.0:3000`) ويوفر نقطة فحص الحالة `/health`.

## إعداد قاعدة البيانات (Supabase)

نفّذ ملفات SQL التالية بالترتيب في **Supabase > SQL Editor** عند التهيئة الأولى أو الترقية:
1. `supabase-setup.sql` (تحديث الملفات الشخصية، `is_admin()`، `is_active_user()`، الأعمدة الإضافية والفهارس)
2. `supabase-dossiers.sql` (جدول `dossier_receptions` وسياسات الأمان)
3. `supabase-bons.sql` (جدول `bon_sorties` وسياسات الأمان)
